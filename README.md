# Gemini Django AI API

A simple AI backend built with **Django** and the **Google Gemini API**.

This project demonstrates how to take an LLM API call and expose it through a backend REST API with request validation, error handling, retries, and structured responses.

## Architecture

```text
Client
   ↓
Django REST API
   ↓
Google Gemini API
   ↓
Django Backend
   ↓
JSON Response
```

## Features

- Gemini LLM API integration
- Django REST API endpoint
- `POST /api/ask/` endpoint
- JSON request handling and validation
- HTTP method validation
- Error handling
- Retry logic with exponential backoff
- Structured JSON output from Gemini
- AI response validation
- API testing with Thunder Client
- API key management using `.env`

## API Usage

### Endpoint

```text
POST /api/ask/
```

### Request

```json
{
    "question": "What is an API?"
}
```

### Response

```json
{
    "answer": "An API is a way for software systems to communicate with each other.",
    "topic": "API"
}
```

The `answer` and `topic` are generated by Gemini.

## Error Handling

The backend validates requests before calling the AI service.

Examples of handled errors include:

- Invalid JSON
- Missing or empty questions
- Unsupported HTTP methods
- Invalid AI responses
- AI/API failures

Example:

```json
{
    "error": "Question is required."
}
```

The API also uses appropriate HTTP status codes such as `400`, `405`, and `502`.

## Retry Logic

The project implements retry logic with exponential backoff for API failures.

```text
Attempt 1
   ↓
wait 1 second
   ↓
Attempt 2
   ↓
wait 2 seconds
   ↓
Attempt 3
```

Retries are limited because permanent errors, such as an invalid model name, will not be fixed by repeatedly sending the same request.

## Setup

### 1. Clone the repository

```bash
git clone <repository-url>
cd gemini-django-ai-api
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure the Gemini API key

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key_here
```

The `.env` file is excluded from Git using `.gitignore`.

### 5. Run migrations

```bash
python manage.py migrate
```

### 6. Start the server

```bash
python manage.py runserver
```

The API will be available at:

```text
http://127.0.0.1:8000/api/ask/
```
